Cases

Each case stays a draft until you have checked every finding and signed it.

  1. Point it at a folder of evidence. Logs, disk images, memory dumps or ZIP files. Nothing in the folder is changed.
  2. It reads everything and lists what it found. Every finding points at the exact line it came from, so you can check it.
  3. You decide, sign and export. Accept or reject each finding. Only a signed case becomes a final report.

                    Help

                    How a review works

                    The tool does the reading. You make the calls. For each finding, open it, look at the evidence line it points to, and accept it if it is real or reject it with a reason. When every finding has a decision, sign the draft, then export the final report.

                    Words used here

                    Finding
                    Something the tool thinks is worth your attention, with the exact place in the evidence that made it think so.
                    Fingerprint
                    A long code worked out from a file's contents. If the file changes by even one letter, the code changes. You paste it back to prove you are signing the same draft the run wrote.
                    Attack path
                    The usual stages of a break-in, from getting in to taking data out. It shows which stages this case has evidence for.
                    Not fully analysed
                    Parts of the evidence the tool could not read. No findings there does not mean nothing happened there.
